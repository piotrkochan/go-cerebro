# Entra ID Auth Example

This example shows Go Cerebro configured for Microsoft Entra ID sign-in.

Use [application.yaml](./application.yaml) as the starting point and set the required environment variables:

- `ENTRA_ID_TENANT_ID`
- `ENTRA_ID_CLIENT_ID`
- `ENTRA_ID_CLIENT_SECRET`
- `APPLICATION_SECRET`
- `ES_USERNAME`
- `ES_PASSWORD`

Full setup notes are in [docs/auth-entra-id.md](../../docs/auth-entra-id.md).
